# 模型与厂商操作指南

1. 在操作系统中设置 Provider API Key 环境变量，并重启 AgentHub。
2. 打开 AgentHub 的“模型与厂商”。
3. 新增 Provider，填写 ID、协议、Base URL、环境变量名和模型列表。
4. 点击“测试连接”，确认凭据和 `/v1/models` 可达。
5. 分别在 Codex、Claude Code 卡片中选择 Provider 与模型，保存默认路由。
6. 点击“启用客户端接管”。AgentHub 会备份配置并写入本地网关地址。
7. 完整退出并重新启动 Codex 或 Claude Code，使客户端重新读取配置。
8. 新会话自动跟随默认路由；老会话可在“会话总览”点击“模型路由”固定到指定模型，或持续跟随默认。首次接管时无法可靠确认原路由的历史会话会显示“未绑定”，必须先明确选择后再恢复。

## 恢复原配置

在客户端路由卡片点击“恢复原配置”。只有当前文件仍与 AgentHub 注入后的 SHA-256 一致时才会自动恢复；若检测到外部修改，AgentHub 会停止覆盖并提示手工确认。

## 已知首版边界

- 自动 fallback 默认关闭。
- 跨协议流会在上游结束后转换并重放，首个输出事件延迟高于同协议透传。
- Provider 健康检查只验证模型目录；真实生成能力仍需用 Codex/Claude Code 测试会话验证。
