# AgentHub V1 会话原型说明

本文记录早期会话管理界面的目标交互，用于解释 [`agent_hub_prototype_v3.html`](./agent_hub_prototype_v3.html)。HTML 是历史探索性原型，不代表当前产品规则；当前范围以 [`../README.md`](../README.md) 和对应模块 `requirements.md` 为准。

## 首页

核心统计展示会话总数、执行中、等待授权或输入、等待验收和执行中断。Agent 工具数、进程数和窗口数只放在工具管理或诊断信息中。

“待处理”区域展示 Agent、会话名称、关注原因、当前规划或最近活动、更新时间和“打开会话”入口。当前 Sessions 需求已增加独立的用户跟进标记；该历史原型尚未展示此能力。

“正在运行”调整为“全部活跃会话”，包含执行中、等待授权、等待输入和等待验收；已经中断的会话进入待处理区域和全部会话页面。

## 会话卡片

会话卡片以内部会话而不是运行实例为中心，优先展示：

- Agent 和会话名称。
- 项目或工作目录。
- 统一状态及待处理原因。
- Agent 提供的当前目标、步骤或 Todo。
- 最近活动、更新时间和状态来源。
- 精确打开该会话的入口。

PID、窗口数、进程名称和终端类型只在详情或诊断区域展示。Agent 未提供规划时不显示推测进度。

## Agent 管理

每个 Agent 分别展示会话发现、状态识别、规划读取、事件订阅和精确恢复能力，以及完整接入、部分接入或有限接入等级。探测操作应验证真实 Agent 连接、会话列表、状态数据和恢复入口，并显示具体失败原因。

只能检测应用或激活窗口的 Agent 标记为有限接入，不进入首页核心会话统计。

## 设置

设置页只保留全局选项，例如状态刷新间隔、启动后打开浏览器、默认终端、桌面通知和数据存储位置。Agent 的识别、连接和能力配置放在 Agent 管理页面。

## 原型非目标

- 该早期会话原型不包含直接回复、权限批准或 Workflows 任务编排界面。
- 不提供人工修改待处理状态的入口。
- 不把进程和窗口管理作为产品核心导航。
- 不在缺少 Agent 原生数据时生成规划或完成百分比。
