# 通过适配器管理 Skill、MCP Server 和插件

## 背景

不同 Agent 保存和操作能力的方式不同。Skill 通常是目录，MCP Server 通常是配置项或进程，插件则可能同时携带多种能力。

## 决策

采用统一的能力清单、目录同源共享和审计术语，但把发现、原生注册、加载验证和变更操作保留在“能力类型专用 + Agent 专用”的适配器中。Skill、目录型 MCP 和 Agent 插件都可以通过平台目录链接引用同一来源；链接成功不等于 Agent 已经加载，必须由对应 Adapter 验证。不得强行把三种能力压缩为同一个生命周期状态机。

## 影响

UI 可以提供一致的管理体验，同时保留各能力的原生语义。跨能力类型的生命周期操作需要显式编排，不能通过单一 `enabled` 布尔值推断。
