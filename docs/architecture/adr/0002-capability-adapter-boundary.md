# ADR 0002：通过适配器管理 Skill、MCP Server 和插件

- 状态：提议中
- 日期：2026-07-18

## 背景

不同 Agent 保存和操作能力的方式不同。Skill 通常是目录，MCP Server 通常是配置项或进程，插件则可能同时携带多种能力。

## 决策

采用统一的能力清单和审计术语，但把发现、验证和变更操作保留在“能力类型专用 + Agent 专用”的适配器中。不得强行把三种能力塞进同一个文件系统共享状态机。

## 影响

UI 可以提供一致的管理体验，同时保留各能力的原生语义。跨能力类型的生命周期操作需要显式编排，不能通过单一 `enabled` 布尔值推断。
