# 操作与开发指南

本目录保存当前 AgentHub 应用真实可执行的用户操作、开发和维护指南。指南必须与当前代码、入口和跨平台支持状态保持一致，不能把历史原型或已删除应用写成可运行功能。

当前能力管理模块尚未接入统一 AgentHub API/UI，因此暂不提供 Skill、MCP 或插件的用户操作手册。相关功能完成并经过验证后，再按实际入口、支持平台、安全确认和恢复方式补充指南。
